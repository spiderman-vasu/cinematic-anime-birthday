# 🎬 Cinematic Anime Birthday Film

An elegant, premium, aesthetic web-based cinematic slideshow designed with an anime film style. It features high-quality visual transitions, dynamic animations, immersive audio playback, and floating sakura (cherry blossom) effects to create an unforgettable birthday experience.

---

## ✨ Features

* **Cinematic Camera Motion:** Uses custom CSS keyframes (`cinematicZoom` and `cinematicFloat`) to give images a subtle, movie-like handheld camera movement.
* **Atmospheric Overlays:** Includes a radial vignette gradient, interactive light leaks, and a vintage film grain texture overlay.
* **Aesthetic Typography:** Clean, minimal, and beautifully spaced typography utilizing the *Cormorant Garamond* serif font with smooth text reveal animations.
* **Floating Sakura Petals:** A dynamic particle effect that drops cherry blossom petals across specific emotional frames of the story.
* **Audio Sync:** Plays background music seamlessly on user interaction (to bypass browser autoplay restrictions).
* **Mobile-First Aspect Ratio:** Tailored perfectly for mobile screens ($9:16$ vertical cinema aspect ratio), matching modern video formats like Reels/TikToks.
